# 🎯 AI Career Advisor

An intelligent career guidance web app that matches your skills to ideal careers.

## 🛠 Tech Stack
- **Frontend:** HTML5 + CSS3 + JavaScript
- **Backend:** Python + Flask
- **Database:** SQLite
- **Auth:** Flask Session + Password Hashing (PBKDF2)
- **AI Logic:** Career & Skill Matching

## 📦 Setup

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
